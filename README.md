# 💌 LoveEvol — Интерактивная платформа романтических приглашений

**LoveEvol** — веб-платформа для создания персонализированных интерактивных открыток-приглашений на свидание с живым мобильным предпросмотром, анимациями, музыкальной шкатулкой, любовными купонами и облачным кабинетом отслеживания ответов на базе **Vercel Serverless Postgres**.

---

## ✨ Главные возможности

- **Пошаговый визуальный конструктор (6 шагов) + Live Mobile Preview:**
  - Именное обращение (`{name}`, `{recipient}`, `{sender}`), 6 дизайнерских тем (вайбов) и 8 видов парящих частиц.
  - Интерактивный конверт с сургучной печатью на входе.
  - **5 режимов кнопки «Нет»:** убегание с мольбами, рост кнопки «Да», уменьшение кнопки «Нет», телепортация с прозрачностью и превращение «Нет» во вторую кнопку «Да! 💖».
  - **AI-генератор романтических текстов** с автоподстановкой имени и вайба (7 сценариев).
- **Музыка и звуковые эффекты (Web Audio API):**
  - Встроенный полифонический синтезатор романтических мелодий (*Moonlight Waltz*, *Paris Café*, *Starry Lullaby*) без внешних CORS-зависимостей.
  - Запись голосового приглашения прямо с микрофона и загрузка MP3 в БД.
  - Тактильные звуковые эффекты открытия конверта, кликов и уворачивания кнопки «Нет».
- **Интерактив для гостя:**
  - Выбор активностей (до 8 вариантов + возможность предложить **свою идею свидания**).
  - Выбор даты и времени + экспорт события в **Google Calendar** и **.ics (Apple/Outlook)**.
  - **Живой таймер обратного отсчета** до встречи (`дней : часов : минут : секунд`).
  - **Колода любовных купонов** с перфорацией, которые половинка может забрать в один клик.
  - **VIP-билет на свидание (Date Pass)** с кнопками **2ГИС / Google Maps** и скачиванием билета в высоком качестве **PNG**.
  - **Любовный мини-квиз** (до 5 вопросов с прогресс-баром), секретный пин-код для альбома общих воспоминаний с Lightbox, быстрые эмодзи-реакции и личная записка автору.
- **Облачная база данных Vercel Postgres & Личный кабинет (`/dashboard`):**
  - Хранение приглашений, ответов гостей и загруженных фото/голосовых файлов (`media_assets`) напрямую в **Vercel Serverless Postgres (Neon)**.
  - Красивые именные ссылки `/invite/for-aruzhan` и генерация QR-кодов.
  - Отслеживание просмотров (`views_count`, статус `Просмотрено 👀`), автообновление в реальном времени (`Live`), редактирование (`/?edit=...`) и дублирование (`/?duplicate=...`) шаблонов.
  - Мгновенные уведомления в **Telegram** при открытии открытки, нажатии «ДА», выборе купонов и отправке записки.

## 🛠 Технологический стек

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion, Zustand (с автосохранением черновика), Lucide Icons, Canvas Confetti.
- **Database & Media Storage:** Vercel Serverless Postgres (`@neondatabase/serverless`) + таблицы `invitations` и `media_assets` (с автоматической инициализацией схемы), поддержка Vercel Blob / Supabase как опциональных провайдеров.
- **API Endpoints:**
  - `GET /api/health` — статус подключения и задержка до Vercel Postgres.
  - `GET / POST / PATCH / PUT / DELETE /api/invitations` — CRUD приглашений, трекинг открытий и ответы гостей.
  - `POST /api/upload` & `GET /api/media/[id]` — загрузка и раздача фото и голосовых сообщений из облачной БД.
  - `GET /api/og` — динамическая генерация именных OpenGraph-карточек (Edge Runtime).

## 🚀 Локальный запуск

```bash
npm install
# Подтянуть переменные окружения Vercel Postgres в .env.local:
npx vercel env pull .env.local
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) для конструктора и [http://localhost:3000/dashboard](http://localhost:3000/dashboard) для личного кабинета.
